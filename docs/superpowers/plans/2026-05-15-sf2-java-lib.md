# SF2 Java Library Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Java 21 library that parses binary SF2 files into a mutable in-memory model and serializes them back with binary-exact round-trip guarantee.

**Architecture:** Four cleanly separated packages: `model` (mutable POJOs), `parser` (binary → model), `serializer` (model → binary), `json` (deferred to separate change). Parser mirrors the C++ `DriverInfo` parse structure. Serializer writes blocks in canonical order.

**Tech Stack:** Java 21, Maven, JUnit 5, Spotless (Google Java Format), zero runtime dependencies.

```java
package io.sf2.sidfactory2.parser;

import io.sf2.sidfactory2.Sf2ParseException;
import java.io.IOException;
import java.io.InputStream;

public class Sf2Reader {
    private final byte[] data;
    private int pos;
    private final int end;

    public Sf2Reader(byte[] data) {
        this.data = data;
        this.pos = 0;
        this.end = data.length;
    }

    public Sf2Reader(byte[] data, int start, int end) {
        this.data = data;
        this.pos = start;
        this.end = end;
    }

    public int readByte() throws Sf2ParseException {
        if (pos >= end) throw new Sf2ParseException("Unexpected end of data at offset " + pos);
        return data[pos++] & 0xFF;
    }

    public int readWord() throws Sf2ParseException {
        int lo = readByte();
        int hi = readByte();
        return (hi << 8) | lo;
    }

    public String readNullTerminatedString() throws Sf2ParseException {
        StringBuilder sb = new StringBuilder();
        while (pos < end) {
            int b = readByte();
            if (b == 0) break;
            sb.append((char) b);
        }
        return sb.toString();
    }

    public byte[] readBytes(int count) throws Sf2ParseException {
        if (pos + count > end) throw new Sf2ParseException("Unexpected end of data: need " + count + " bytes at offset " + pos);
        byte[] result = new byte[count];
        System.arraycopy(data, pos, result, 0, count);
        pos += count;
        return result;
    }

    public byte[] readRemaining() {
        if (pos >= end) return new byte[0];
        byte[] result = new byte[end - pos];
        System.arraycopy(data, pos, result, 0, end - pos);
        pos = end;
        return result;
    }

    public int getPos() { return pos; }
    public boolean isAtEnd() { return pos >= end; }
}

- [ ] **Step 2: Write Sf2Parser header parsing**

Mirrors `DriverInfo::Parse()` and `ParseHeader()` from `driver_info.cpp:33-293`.

```java
package io.sf2.sidfactory2.parser;

import io.sf2.sidfactory2.Sf2ParseException;
import io.sf2.sidfactory2.model.*;
import java.io.IOException;
import java.io.InputStream;
import java.nio.file.Files;
import java.nio.file.Path;

public class Sf2Parser {
    private static final int EXPECTED_SIGNATURE = 0x1337;

    public Sf2Model parse(Path file) throws Sf2ParseException, IOException {
        byte[] fileBytes = Files.readAllBytes(file);
        return parse(fileBytes);
    }

    public Sf2Model parse(byte[] fileBytes) throws Sf2ParseException {
        Sf2Reader reader = new Sf2Reader(fileBytes);

        // Read file header: load address (2 bytes) + signature (2 bytes)
        int loadAddress = reader.readWord();
        int signature = reader.readWord();

        if (signature != EXPECTED_SIGNATURE) {
            throw new Sf2ParseException(
                "Invalid SF2 signature: 0x" + Integer.toHexString(signature) +
                ", expected 0x" + Integer.toHexString(EXPECTED_SIGNATURE));
        }

        Sf2Model model = new Sf2Model();
        model.setLoadAddress(loadAddress);
        model.setSignature(signature);

        // Parse metadata blocks starting after header
        parseHeader(model, reader, fileBytes);

        // Player code: from after metadata terminator to song data start
        // This requires knowing where song data starts — handled after parsing all blocks
        // For now, store remaining bytes after metadata terminator
        int playerCodeStart = reader.getPos();
        // Song data starts at CodeTop + CodeSize from descriptor
        int codeTop = model.getDescriptor().getDriverCodeTop();
        int codeSize = model.getDescriptor().getDriverCodeSize();
        int songDataStart = codeTop - loadAddress + 2 + codeSize;

        if (songDataStart > fileBytes.length) {
            throw new Sf2ParseException("Song data start offset " + songDataStart + " exceeds file size " + fileBytes.length);
        }

        // Player code is between metadata terminator and song data
        // But we need to find the metadata terminator position first
        // The reader is now past all metadata blocks, at the 0xFF terminator position + 1
        // Player code = bytes from reader.getPos() to songDataStart
        int pcStart = reader.getPos();
        if (pcStart < songDataStart) {
            byte[] playerCode = new byte[songDataStart - pcStart];
            System.arraycopy(fileBytes, pcStart, playerCode, 0, songDataStart - pcStart);
            model.setPlayerCode(playerCode);
        }

        // Parse song data (tables, order lists, sequences)
        parseSongData(model, reader, fileBytes, songDataStart);

        // Parse auxiliary data
        parseAuxiliaryData(model, fileBytes, loadAddress);

        return model;
    }

    private void parseHeader(Sf2Model model, Sf2Reader reader, byte[] fileBytes) throws Sf2ParseException {
        while (true) {
            int blockId = reader.readByte();

            if (blockId == HeaderBlockId.END.id()) {
                break;
            }

            int blockSize = reader.readByte();
            int blockEnd = reader.getPos() + blockSize;

            Sf2Reader blockReader = new Sf2Reader(fileBytes, reader.getPos(), blockEnd);

            switch (blockId) {
                case 1 -> parseDescriptor(model, blockReader);
                case 2 -> parseDriverCommon(model, blockReader);
                case 3 -> parseDriverTables(model, blockReader);
                case 4 -> parseInstrumentDescriptor(model, blockReader);
                case 5 -> parseMusicData(model, blockReader);
                case 6 -> parseTableColorRules(model, blockReader);
                case 7 -> parseTableInsDelRules(model, blockReader);
                case 8 -> parseTableActionRules(model, blockReader);
                case 9 -> parseInstDataDescriptor(model, blockReader);
                default -> throw new Sf2ParseException("Unknown block ID: 0x" + Integer.toHexString(blockId));
            }

            reader.pos = blockEnd;
        }
    }

    private void parseDescriptor(Sf2Model model, Sf2Reader reader) throws Sf2ParseException {

    private void parseSongData(Sf2Model model, Sf2Reader reader, byte[] fileBytes, int songDataStart) throws Sf2ParseException {
        // Read table data based on table definitions
        for (TableDefinition td : model.getTables()) {
            int address = td.getAddress();
            int colCount = td.getColumnCount();
            int rowCount = td.getRowCount();
            int dataSize = colCount * rowCount;

            // Convert C64 address to file offset
            int fileOffset = address - model.getLoadAddress() + 2;
            if (fileOffset < 0 || fileOffset + dataSize > fileBytes.length) {
                // Table data might be in the packed song data area — skip for now
                // The serializer will handle this based on packed addresses
                continue;
            }

            byte[] tableBytes = new byte[dataSize];
            System.arraycopy(fileBytes, fileOffset, tableBytes, 0, dataSize);
            model.getTableData().put(td.getId(), new TableData(tableBytes, colCount, rowCount, td.getDataLayout()));
        }

        // Read order list pointers and unpack order lists
        parseOrderLists(model, fileBytes);

        // Read sequence pointers and unpack sequences
        parseSequences(model, fileBytes);
    }

    private void parseOrderLists(Sf2Model model, byte[] fileBytes) throws Sf2ParseException {
        MusicData md = model.getMusicData();
        int trackCount = md.getTrackCount();
        if (trackCount == 0) return;

        // Read order list pointer arrays (low + high bytes)
        int olPtrLowOffset = md.getTrackOrderListPointersLowAddress() - model.getLoadAddress() + 2;
        int olPtrHighOffset = md.getTrackOrderListPointersHighAddress() - model.getLoadAddress() + 2;

        for (int t = 0; t < trackCount; t++) {
            int lo = fileBytes[olPtrLowOffset + t] & 0xFF;
            int hi = fileBytes[olPtrHighOffset + t] & 0xFF;
            int olAddress = (hi << 8) | lo;
            int olFileOffset = olAddress - model.getLoadAddress() + 2;

            List<OrderListEntry> entries = unpackOrderList(fileBytes, olFileOffset);
            model.getOrderLists().put(t, entries);
        }
    }

    private List<OrderListEntry> unpackOrderList(byte[] fileBytes, int fileOffset) throws Sf2ParseException {
        List<OrderListEntry> entries = new ArrayList<>();
        int pos = fileOffset;
        int currentTranspose = 0;

        while (pos < fileBytes.length) {
            int b = fileBytes[pos++] & 0xFF;

            if (b == 0xFE) {
                // Stop marker
                break;
            } else if (b == 0xFF) {
                // Loop marker — next byte is loop index, stop parsing
                break;
            } else if (b >= 0x80 && b <= 0xFD) {
                // Transposition value
                currentTranspose = b - 0x80;
            } else {
                // Sequence index
                entries.add(new OrderListEntry(currentTranspose, b));
            }
        }

        return entries;
    }

    private void parseSequences(Sf2Model model, byte[] fileBytes) throws Sf2ParseException {
        MusicData md = model.getMusicData();
        int seqCount = md.getSequenceCount();
        if (seqCount == 0) return;

        // Read sequence pointer arrays
        int seqPtrLowOffset = md.getSequencePointersLowAddress() - model.getLoadAddress() + 2;
        int seqPtrHighOffset = md.getSequencePointersHighAddress() - model.getLoadAddress() + 2;

        for (int s = 0; s < seqCount; s++) {
            int lo = fileBytes[seqPtrLowOffset + s] & 0xFF;
            int hi = fileBytes[seqPtrHighOffset + s] & 0xFF;
            int seqAddress = (hi << 8) | lo;
            int seqFileOffset = seqAddress - model.getLoadAddress() + 2;

            List<SequenceEvent> events = unpackSequence(fileBytes, seqFileOffset);
            model.getSequences().put(s, events);
        }
    }

    private List<SequenceEvent> unpackSequence(byte[] fileBytes, int fileOffset) throws Sf2ParseException {
        List<SequenceEvent> events = new ArrayList<>();
        int pos = fileOffset;
        Integer currentDuration = null;
        Integer currentInstrument = null;
        Integer currentCommand = null;

        while (pos < fileBytes.length) {
            int b = fileBytes[pos++] & 0xFF;

            if (b == 0x7F) {
                break;
            } else if (b == 0x00) {
                // Note off
                var e = new SequenceEvent();
                e.setNoteOff(true);
                e.setDuration(currentDuration);
                e.setInstrument(currentInstrument);
                e.setCommand(currentCommand);
                events.add(e);
            } else if (b >= 0x01 && b <= 0x6F) {
                // Note value
                var e = new SequenceEvent();
                e.setNote(b);
                e.setDuration(currentDuration);
                e.setInstrument(currentInstrument);
                e.setCommand(currentCommand);
                events.add(e);
            } else if (b == 0x7E) {
                // Gate ON
                var e = new SequenceEvent();
                e.setGate(true);
                e.setDuration(currentDuration);
                events.add(e);
            } else if (b >= 0x80 && b <= 0x8F) {
                // Duration token
                currentDuration = b & 0x0F;
            } else if (b >= 0x90 && b <= 0x9F) {
                // Tie-note duration token
                currentDuration = b & 0x0F;
                // Next byte will be the note
                if (pos < fileBytes.length) {
                    int note = fileBytes[pos++] & 0xFF;
                    var e = new SequenceEvent();
                    e.setNote(note);
                    e.setTie(true);
                    e.setDuration(currentDuration);
                    e.setInstrument(currentInstrument);
                    e.setCommand(currentCommand);
                    events.add(e);
                }
            } else if (b >= 0xA0 && b <= 0xBF) {
                // Instrument change
                currentInstrument = b & 0x1F;
            } else if (b >= 0xC0) {
                // Command change
                currentCommand = b & 0x3F;
            }
        }

        return events;
    }

    private void parseAuxiliaryData(Sf2Model model, byte[] fileBytes, int loadAddress) throws Sf2ParseException {
        // Auxiliary data pointer is at $0FFB in C64 memory
        // File offset = 0x0FFB - loadAddress + 2
        // But we need to read it from the file at the correct offset
        // The pointer is stored at absolute address $0FFB, which in the file is at:
        // Actually, $0FFB is in the zero page — it's written by the editor
        // For parsing, we need to find it in the file header area
        // The pointer is at file offset: 0x0FFB - loadAddress + 2
        int auxPtrOffset = 0x0FFB - loadAddress + 2;
        if (auxPtrOffset < 0 || auxPtrOffset + 2 > fileBytes.length) return;

        int auxAddress = ((fileBytes[auxPtrOffset + 1] & 0xFF) << 8) | (fileBytes[auxPtrOffset] & 0xFF);
        if (auxAddress == 0) return;

        int auxFileOffset = auxAddress - loadAddress + 2;
        if (auxFileOffset < 0 || auxFileOffset >= fileBytes.length) return;

        Sf2Reader auxReader = new Sf2Reader(fileBytes, auxFileOffset, fileBytes.length);
        parseAuxiliaryChunks(model, auxReader);
    }

    private void parseAuxiliaryChunks(Sf2Model model, Sf2Reader reader) throws Sf2ParseException {
        while (!reader.isAtEnd()) {
            int type = reader.readByte();
            int version = reader.readWord();
            int dataSize = reader.readWord();

            if (type == 0 && version == 0 && dataSize == 0) break;

            switch (type) {
                case 1 -> parseEditingPreferences(model, reader, version, dataSize);
                case 2 -> parseHardwarePreferences(model, reader, version, dataSize);
                case 3 -> parsePlayMarkers(model, reader, version, dataSize);
                case 4 -> parseTableText(model, reader, version, dataSize);
                case 5 -> parseSongs(model, reader, version, dataSize);
                default -> {
                    // Skip unknown chunk
                    reader.pos += dataSize;
                }
            }
        }
    }

    private void parseEditingPreferences(Sf2Model model, Sf2Reader reader, int version, int dataSize) {
        EditingPreferences ep = new EditingPreferences();
        ep.setNotationMode(reader.readByte());
        ep.setEventPosHighlightOffset(reader.readByte());
        ep.setEventPosHighlightInterval(reader.readByte());
        model.getAuxiliaryData().setEditingPreferences(ep);
    }

    private void parseHardwarePreferences(Sf2Model model, Sf2Reader reader, int version, int dataSize) {
        HardwarePreferences hp = new HardwarePreferences();
        hp.setSidModel(reader.readByte());
        hp.setRegion(reader.readByte());
        model.getAuxiliaryData().setHardwarePreferences(hp);
    }

    private void parsePlayMarkers(Sf2Model model, Sf2Reader reader, int version, int dataSize) throws Sf2ParseException {
        PlayMarkers pm = new PlayMarkers();
        int layerCount = reader.readByte();
        for (int l = 0; l < layerCount; l++) {
            PlayMarkerLayer layer = new PlayMarkerLayer();
            int markerCount = reader.readByte();
            for (int m = 0; m < markerCount; m++) {
                // Signed 32-bit LE
                int b0 = reader.readByte();
                int b1 = reader.readByte();
                int b2 = reader.readByte();
                int b3 = reader.readByte();
                int pos = b0 | (b1 << 8) | (b2 << 16) | (b3 << 24);
                layer.getEventPositions().add(pos);
            }
            pm.getLayers().add(layer);
        }
        model.getAuxiliaryData().setPlayMarkers(pm);
    }

    private void parseTableText(Sf2Model model, Sf2Reader reader, int version, int dataSize) throws Sf2ParseException {
        TableText tt = new TableText();
        int tableCount = reader.readByte();
        for (int t = 0; t < tableCount; t++) {
            TableTextBucket bucket = new TableTextBucket();
            bucket.setTableId(reader.readWord() | (reader.readWord() << 16)); // 32-bit LE
            int layerCount = reader.readWord();
            for (int l = 0; l < layerCount; l++) {
                TableTextLayer layer = new TableTextLayer();
                int entryCount = reader.readWord();
                for (int e = 0; e < entryCount; e++) {
                    int length = reader.readByte();
                    byte[] textBytes = reader.readBytes(length);
                    layer.getEntries().add(new String(textBytes));
                }
                bucket.getLayers().add(layer);
            }
            tt.getBuckets().add(bucket);
        }
        model.getAuxiliaryData().setTableText(tt);
    }

    private void parseSongs(Sf2Model model, Sf2Reader reader, int version, int dataSize) throws Sf2ParseException {
        Songs songs = new Songs();
        songs.setSongCount(reader.readByte());
        songs.setSelectedSong(reader.readByte());
        for (int s = 0; s < songs.getSongCount(); s++) {
            int length = reader.readByte();
            if (length > 0) {
                byte[] nameBytes = reader.readBytes(length);
                songs.getSongNames().add(new String(nameBytes));
            } else {
                songs.getSongNames().add("");
            }
        }
        model.getAuxiliaryData().setSongs(songs);
    }
}

import java.io.ByteArrayOutputStream;
import java.io.IOException;

public class Sf2Writer {
    private final ByteArrayOutputStream out = new ByteArrayOutputStream();

    public void writeByte(int value) {
        out.write(value & 0xFF);
    }

    public void writeWord(int value) {
        out.write(value & 0xFF);
        out.write((value >> 8) & 0xFF);
    }

    public void writeNullTerminatedString(String value) {
        for (int i = 0; i < value.length(); i++) {
            writeByte(value.charAt(i));
        }
        writeByte(0);
    }

    public void writeBytes(byte[] data) {
        try {
            out.write(data);
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }

    public byte[] toByteArray() {
        return out.toByteArray();
    }

    public int size() {
        return out.size();
    }
}

```java
package io.sf2.sidfactory2.serializer;

import io.sf2.sidfactory2.model.*;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

public class Sf2Serializer {

    public void serialize(Sf2Model model, Path outputFile) throws IOException {
        byte[] bytes = serialize(model);
        Files.write(outputFile, bytes);
    }

    public byte[] serialize(Sf2Model model) {
        Sf2Writer writer = new Sf2Writer();

        // File header
        writer.writeWord(model.getLoadAddress());
        writer.writeWord(model.getSignature());

        // Metadata blocks in canonical order
        serializeDescriptor(model, writer);
        serializeDriverCommon(model, writer);
        serializeDriverTables(model, writer);
        serializeInstrumentDescriptor(model, writer);
        serializeMusicData(model, writer);
        serializeTableColorRules(model, writer);
        serializeTableInsDelRules(model, writer);
        serializeTableActionRules(model, writer);
        serializeInstDataDescriptor(model, writer);

        // Metadata terminator
        writer.writeByte(0xFF);

        // Player code
        writer.writeBytes(model.getPlayerCode());

        // Song data (tables, order lists, sequences)
        serializeSongData(model, writer);

        // Auxiliary data
        serializeAuxiliaryData(model, writer);

        return writer.toByteArray();
    }

    private void serializeDescriptor(Sf2Model model, Sf2Writer writer) {
        Descriptor d = model.getDescriptor();
        writer.writeByte(0x01); // block ID

        // Calculate size
        int size = 1 + 2; // driverType + driverSize
        size += d.getDriverName().length() + 1; // null-terminated
        size += 2 + 2 + 1 + 1; // codeTop + codeSize + major + minor
        if (d.getDriverVersionRevision() != 0 || true) size += 1; // revision (always write)

        writer.writeByte(size);
        writer.writeByte(d.getDriverType());
        writer.writeWord(d.getDriverSize());
        writer.writeNullTerminatedString(d.getDriverName());
        writer.writeWord(d.getDriverCodeTop());
        writer.writeWord(d.getDriverCodeSize());
        writer.writeByte(d.getDriverVersionMajor());
        writer.writeByte(d.getDriverVersionMinor());
        writer.writeByte(d.getDriverVersionRevision());
    }

    private void serializeDriverCommon(Sf2Model model, Sf2Writer writer) {
        DriverCommon dc = model.getDriverCommon();
        writer.writeByte(0x02);
        writer.writeByte(40); // fixed size: 19 words + 2 bytes = 38 + 2 reserved = 40

        writer.writeWord(dc.getInitAddress());
        writer.writeWord(dc.getStopAddress());
        writer.writeWord(dc.getUpdateAddress());
        writer.writeWord(dc.getSidChannelOffsetAddress());
        writer.writeWord(dc.getDriverStateAddress());
        writer.writeWord(dc.getTickCounterAddress());
        writer.writeWord(dc.getOrderListIndexAddress());
        writer.writeWord(dc.getSequenceIndexAddress());
        writer.writeWord(dc.getSequenceInUseAddress());
        writer.writeWord(dc.getCurrentSequenceAddress());
        writer.writeWord(dc.getCurrentTransposeAddress());
        writer.writeWord(dc.getCurrentSequenceEventDurationAddress());
        writer.writeWord(dc.getNextInstrumentAddress());
        writer.writeWord(dc.getNextCommandAddress());
        writer.writeWord(dc.getNextNoteAddress());
        writer.writeWord(dc.getNextNoteIsTiedAddress());
        writer.writeWord(dc.getTempoCounterAddress());
        writer.writeWord(dc.getTriggerSyncAddress());
        writer.writeByte(dc.getNoteEventTriggerSyncValue());
        writer.writeByte(dc.getReservedByte());
        writer.writeWord(dc.getReservedWord());
    }

    private void serializeDriverTables(Sf2Model model, Sf2Writer writer) {
        writer.writeByte(0x03);

        // Calculate size
        Sf2Writer tempWriter = new Sf2Writer();
        for (TableDefinition td : model.getTables()) {
            tempWriter.writeByte(td.getType().value());
            tempWriter.writeByte(td.getId());
            tempWriter.writeByte(td.getTextFieldSize());
            tempWriter.writeNullTerminatedString(td.getName());
            tempWriter.writeByte(td.getDataLayout().value());

            int props = 0;
            if (td.isPropertyEnabledInsertDelete()) props |= TableProperty.ENABLE_INSERT_DELETE.bit();
            if (td.isPropertyLayoutVertically()) props |= TableProperty.LAYOUT_ADD_VERTICALLY.bit();
            if (td.isPropertyIndexAsContinuousMemory()) props |= TableProperty.INDEX_AS_CONTINUOUS_MEMORY.bit();
            tempWriter.writeByte(props);

            tempWriter.writeByte(td.getInsertDeleteRuleId());
            tempWriter.writeByte(td.getEnterActionRuleId());
            tempWriter.writeByte(td.getColorRuleId());
            tempWriter.writeWord(td.getAddress());
            tempWriter.writeWord(td.getColumnCount());
            tempWriter.writeWord(td.getRowCount());
            tempWriter.writeByte(td.getVisibleRowCount());
        }
        tempWriter.writeByte(0xFF); // terminator

        byte[] blockData = tempWriter.toByteArray();
        writer.writeByte(blockData.length);
        writer.writeBytes(blockData);
    }

    private void serializeInstrumentDescriptor(Sf2Model model, Sf2Writer writer) {
        InstrumentDescriptor id = model.getInstrumentDescriptor();
        writer.writeByte(0x04);

        Sf2Writer tempWriter = new Sf2Writer();
        tempWriter.writeByte(id.getCellDescription().size());
        for (String label : id.getCellDescription()) {
            tempWriter.writeNullTerminatedString(label);
        }

        byte[] blockData = tempWriter.toByteArray();
        writer.writeByte(blockData.length);
        writer.writeBytes(blockData);
    }

    private void serializeMusicData(Sf2Model model, Sf2Writer writer) {
        MusicData md = model.getMusicData();
        writer.writeByte(0x05);
        writer.writeByte(18); // fixed size

        writer.writeByte(md.getTrackCount());
        writer.writeWord(md.getTrackOrderListPointersLowAddress());
        writer.writeWord(md.getTrackOrderListPointersHighAddress());
        writer.writeByte(md.getSequenceCount());
        writer.writeWord(md.getSequencePointersLowAddress());
        writer.writeWord(md.getSequencePointersHighAddress());
        writer.writeWord(md.getOrderListSize());
        writer.writeWord(md.getOrderListTrack1Address());
        writer.writeWord(md.getSequenceSize());
        writer.writeWord(md.getSequence00Address());
    }

    private void serializeTableColorRules(Sf2Model model, Sf2Writer writer) {
        List<TableColorRules> groups = model.getColorRules();
        if (groups.isEmpty()) return;

        writer.writeByte(0x06);

        Sf2Writer tempWriter = new Sf2Writer();
        for (TableColorRules group : groups) {
            for (TableColorRule rule : group.getRules()) {
                tempWriter.writeByte(rule.getEvaluationCellIndex());
                tempWriter.writeByte(rule.getEvaluationCellMask());
                tempWriter.writeByte(rule.getEvaluationCellConditionalValue());
                tempWriter.writeByte(rule.getBackgroundColor());
            }
            tempWriter.writeByte(0xFF); // end of group
        }
        tempWriter.writeByte(0xFE); // end of all rules

        byte[] blockData = tempWriter.toByteArray();
        writer.writeByte(blockData.length);
        writer.writeBytes(blockData);
    }

    private void serializeTableInsDelRules(Sf2Model model, Sf2Writer writer) {
        List<TableInsDelRules> groups = model.getInsDelRules();
        if (groups.isEmpty()) return;

        writer.writeByte(0x07);

        Sf2Writer tempWriter = new Sf2Writer();
        for (TableInsDelRules group : groups) {
            for (TableInsDelRule rule : group.getRules()) {
                tempWriter.writeByte(rule.getTargetTableId());

                tempWriter.writeByte(rule.getEvaluationCellIndex());
                tempWriter.writeByte(rule.getEvaluationCellMask());
                tempWriter.writeByte(rule.getEvaluationCellConditionalValue());

        }
        tempWriter.writeByte(0xFE);

        byte[] blockData = tempWriter.toByteArray();
        writer.writeByte(blockData.length);
        writer.writeBytes(blockData);
    }

    private void serializeTableActionRules(Sf2Model model, Sf2Writer writer) {
        List<TableActionRules> groups = model.getActionRules();
        if (groups.isEmpty()) return;

        writer.writeByte(0x08);

        Sf2Writer tempWriter = new Sf2Writer();
        for (TableActionRules group : groups) {
            for (TableActionRule rule : group.getRules()) {
                tempWriter.writeByte(rule.getApplicableCell());

                tempWriter.writeByte(rule.getTargetIndexMask());

    private void serializeInstDataDescriptor(Sf2Model model, Sf2Writer writer) {
        InstDataDescriptor idd = model.getInstDataDescriptor();
        writer.writeByte(0x09);

        Sf2Writer tempWriter = new Sf2Writer();
        tempWriter.writeByte(idd.getPointerDescriptions().size());
        for (InstDataPointerDescription pd : idd.getPointerDescriptions()) {
            tempWriter.writeByte(pd.getTableId());
            tempWriter.writeByte(pd.getInstrumentDataPointerPosition());
            tempWriter.writeByte(pd.getPointerAndValue());
            tempWriter.writeByte(pd.getInstrumentDataConditionalValuePosition());
            tempWriter.writeByte(pd.getConditionValueAndValue());
            tempWriter.writeByte(pd.getConditionEqualityValue());
            tempWriter.writeByte(pd.getTableDataType());
            tempWriter.writeByte(pd.getTableJumpMarkerValuePosition());
            tempWriter.writeByte(pd.getTableJumpMarkerValue());
            tempWriter.writeByte(pd.getTableJumpDestinationIndexPosition());
        }

        byte[] blockData = tempWriter.toByteArray();
        writer.writeByte(blockData.length);
        writer.writeBytes(blockData);
    }

    private void serializeSongData(Sf2Model model, Sf2Writer writer) {
        // Table data
        for (TableDefinition td : model.getTables()) {
            TableData td_data = model.getTableData().get(td.getId());
            if (td_data != null && td_data.getData() != null) {
                writer.writeBytes(td_data.getData());
            }
        }

        // Order list pointer arrays and packed order lists
        serializeOrderLists(model, writer);

        // Sequence pointer arrays and packed sequences
        serializeSequences(model, writer);
    }

    private void serializeOrderLists(Sf2Model model, Sf2Writer writer) {
        int trackCount = model.getMusicData().getTrackCount();
        // Pointer arrays will be written after we know the addresses
        // For round-trip, we use the addresses from the parsed model
        // This is a simplified approach — full packing would recompute addresses

        // Write pointer arrays at their original positions
        // In a full implementation, we'd pack data and update pointers
        // For now, write the packed order list data
        for (int t = 0; t < trackCount; t++) {
            List<OrderListEntry> entries = model.getOrderLists().get(t);
            if (entries != null) {
                byte[] packed = packOrderList(entries);
                writer.writeBytes(packed);
            }
        }
    }

    private void serializeSequences(Sf2Model model, Sf2Writer writer) {
        int seqCount = model.getMusicData().getSequenceCount();
        for (int s = 0; s < seqCount; s++) {
            List<SequenceEvent> events = model.getSequences().get(s);
            if (events != null) {
                byte[] packed = packSequence(events);
                writer.writeBytes(packed);
            }
        }
    }

    private byte[] packOrderList(List<OrderListEntry> entries) {
        Sf2Writer w = new Sf2Writer();
        int currentTranspose = -1;

        for (OrderListEntry entry : entries) {
            if (entry.getTranspose() != currentTranspose) {
                w.writeByte(0x80 + entry.getTranspose());
                currentTranspose = entry.getTranspose();
            }
            w.writeByte(entry.getSequenceIndex());
        }

        w.writeByte(0xFE); // stop marker
        return w.toByteArray();
    }

    private byte[] packSequence(List<SequenceEvent> events) {
        Sf2Writer w = new Sf2Writer();
        Integer lastDuration = null;
        Integer lastInstrument = null;
        Integer lastCommand = null;

        for (SequenceEvent e : events) {
            // Duration
            if (e.getDuration() != null && !e.getDuration().equals(lastDuration)) {
                if (e.isTie()) {
                    w.writeByte(0x90 | e.getDuration());
                } else {
                    w.writeByte(0x80 | e.getDuration());
                }
                lastDuration = e.getDuration();
            }

            // Instrument
            if (e.getInstrument() != null && !e.getInstrument().equals(lastInstrument)) {
                w.writeByte(0xA0 | e.getInstrument());
                lastInstrument = e.getInstrument();
            }

            // Command
            if (e.getCommand() != null && !e.getCommand().equals(lastCommand)) {
                w.writeByte(0xC0 | e.getCommand());
                lastCommand = e.getCommand();
            }

            // Note
            if (e.isNoteOff()) {
                w.writeByte(0x00);
            } else if (e.isGate()) {
                w.writeByte(0x7E);
            } else if (e.getNote() != null) {
                if (e.getNote() >= 1 && e.getNote() <= 0x6F) {
                    w.writeByte(e.getNote());
                }
            }
        }

        w.writeByte(0x7F); // end marker
        return w.toByteArray();
    }

    private void serializeAuxiliaryData(Sf2Model model, Sf2Writer writer) {
        AuxiliaryData aux = model.getAuxiliaryData();

        // EditingPreferences
        Sf2Writer epWriter = new Sf2Writer();
        epWriter.writeByte(aux.getEditingPreferences().getNotationMode());
        epWriter.writeByte(aux.getEditingPreferences().getEventPosHighlightOffset());
        epWriter.writeByte(aux.getEditingPreferences().getEventPosHighlightInterval());
        writeAuxChunk(writer, 1, 1, epWriter.toByteArray());

        // HardwarePreferences
        Sf2Writer hpWriter = new Sf2Writer();
        hpWriter.writeByte(aux.getHardwarePreferences().getSidModel());
        hpWriter.writeByte(aux.getHardwarePreferences().getRegion());
        writeAuxChunk(writer, 2, 1, hpWriter.toByteArray());

        // PlayMarkers
        writePlayMarkers(writer, aux);

        // TableText
        writeTableText(writer, aux);

        // Songs
        writeSongs(writer, aux);

        // Terminator chunk
        writer.writeWord(0); // type=0
        writer.writeWord(0); // version=0
        writer.writeWord(0); // dataSize=0
    }

    private void writeAuxChunk(Sf2Writer writer, int type, int version, byte[] data) {
        writer.writeByte(type);
        writer.writeWord(version);
        writer.writeWord(data.length);
        writer.writeBytes(data);
    }

    private void writePlayMarkers(Sf2Writer writer, AuxiliaryData aux) {
        Sf2Writer pmWriter = new Sf2Writer();
        PlayMarkers pm = aux.getPlayMarkers();
        pmWriter.writeByte(pm.getLayers().size());

        for (PlayMarkerLayer layer : pm.getLayers()) {
            pmWriter.writeByte(layer.getEventPositions().size());
            for (int pos : layer.getEventPositions()) {
                pmWriter.writeByte(pos & 0xFF);
                pmWriter.writeByte((pos >> 8) & 0xFF);
                pmWriter.writeByte((pos >> 16) & 0xFF);
                pmWriter.writeByte((pos >> 24) & 0xFF);
            }
        }

        writeAuxChunk(writer, 3, 2, pmWriter.toByteArray());
    }

    private void writeTableText(Sf2Writer writer, AuxiliaryData aux) {
        Sf2Writer ttWriter = new Sf2Writer();
        TableText tt = aux.getTableText();
        ttWriter.writeByte(tt.getBuckets().size());

        for (TableTextBucket bucket : tt.getBuckets()) {
            ttWriter.writeWord(bucket.getTableId() & 0xFFFF);
            ttWriter.writeWord((bucket.getTableId() >> 16) & 0xFFFF);
            ttWriter.writeWord(bucket.getLayers().size());

            for (TableTextLayer layer : bucket.getLayers()) {
                ttWriter.writeWord(layer.getEntries().size());
                for (String entry : layer.getEntries()) {
                    byte[] textBytes = entry.getBytes();
                    ttWriter.writeByte(textBytes.length);
                    ttWriter.writeBytes(textBytes);
                }
            }
        }

        writeAuxChunk(writer, 4, 2, ttWriter.toByteArray());
    }

    private void writeSongs(Sf2Writer writer, AuxiliaryData aux) {
        Sf2Writer sWriter = new Sf2Writer();
        Songs songs = aux.getSongs();
        sWriter.writeByte(songs.getSongCount());
        sWriter.writeByte(songs.getSelectedSong());

        for (int i = 0; i < songs.getSongCount() && i < songs.getSongNames().size(); i++) {
            String name = songs.getSongNames().get(i);
            byte[] nameBytes = name.getBytes();
            sWriter.writeByte(nameBytes.length);
            sWriter.writeBytes(nameBytes);
        }

        writeAuxChunk(writer, 5, 2, sWriter.toByteArray());
    }
}

If the parser loses information (e.g., doesn't store raw bytes for sections it can't reconstruct), fix the parser.

Common fixes:
1. **Block size mismatch**: The serializer must calculate block sizes exactly as the original file. Use a temp writer to measure size before writing the size byte.
2. **String encoding**: PETSCII vs ASCII. If the original uses PETSCII, we must preserve it. Store raw bytes for strings if needed.
3. **Optional revision byte**: If the original file omits the revision byte, the serializer must also omit it. Add a flag to Descriptor: `boolean hasRevisionByte`.
4. **Order list packing**: The parser must store the original transposition byte positions, not just the logical entries. Or the serializer must produce identical packing.
5. **Sequence packing**: Same issue — the serializer must reproduce the exact byte stream.
